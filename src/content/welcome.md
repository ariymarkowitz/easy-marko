# Welcome to Easy Marko

A minimal markdown editor that works offline.

- Edit on the left, preview on the right
- Switch between **source**, **split** and **preview** views in the toolbar
- Your documents are backed up in this browser automatically

## Maths

Inline maths like $e^{i\pi} + 1 = 0$ and display maths:

$$
\int_{-\infty}^{\infty} e^{-x^2} \, dx = \sqrt{\pi}
$$

## Code

```ts
const greeting = (name: string) => `Hello, ${name}!`;
```

> [!TIP]
> Press `Mod-F` in the editor to find and replace.
