# Easy Marko

<https://ariymarkowitz.github.io/easy-marko>

A simple markdown editor and viewer that runs entirely in the browser, works offline, and installs as a Progressive Web App.

I really designed this app for viewing; the editing is secondary. If you download it as an app, you can open .md files in it natively. It remembers your viewing mode so it will unobtrusively open in the display view.

Built with Solid 2, Vite, CodeMirror 6, markdown-it and KaTeX. Co-written with Claude.
