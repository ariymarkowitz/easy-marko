# Easy Marko

<https://ariymarkowitz.github.io/easy-marko>

A simple markdown editor and viewer that runs entirely in the browser, works offline, and installs as a Progressive Web App.

Features include:
- Simple preview mode. I really designed this app so I could quickly preview markdown files in an easy-to-read format. You just double click a file or drag it in, and the preview pops up. If you were in preview mode last time then the app remembers that.
- Supports any OS with a modern web browser.
- Very simple and easy to use, with no bloat.
- All the usual code editor goodies: wrapping, find/replace, syntax highlighting, etc.
- Automatic backups to local storage, and saving files on your device when installed as a PWA.
- Synced scrolling between source and preview, or jump from one to the other with alt-click.
- Export as an HTML file, in light or dark mode.
- No advertisements, links, upgrades, or achievements.

Built with Solid 2, Vite, CodeMirror 6, markdown-it and KaTeX. Co-written with Claude.
